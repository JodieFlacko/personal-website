# GlassBackdrop Specification

## Overview
- **Target file:** `<page>/GlassBackdrop.tsx`
- **Screenshot:** `docs/design-references/www-nateherk-com-dfc5c2e7/root-8a5edab2/desktop-01-hero-scroll0.png`
- **Interaction model:** scroll-driven (WebGL uniforms bound to scroll position, scroll velocity and the recognition ring's angle)

Three pieces of fixed furniture that live outside `<main>` and are rendered as
one fragment, in source order. None of them is interactive; all three are
`aria-hidden`.

## DOM Structure

```
<>
  <canvas id="glass" class="nh-glass" aria-hidden />     WebGL fluted-glass pane
  <div class="sc-grain" aria-hidden />                    fractal-noise overlay
  <div class="nh-progress" data-sc-progress aria-hidden /> reading-progress hairline
</>
```

Order matters only for the grain, which must paint over the glass and under the
planes. The engine finds the progress bar by its `[data-sc-progress]` attribute,
the controller finds the canvas by `id="glass"`.

## Computed Styles (exact values from getComputedStyle)

### `canvas#glass.nh-glass`
- position: fixed; inset: 0
- width: 1430px (`100vw`); height: 900px (`100vh`, then `100lvh`)
- zIndex: 0 · maxWidth: 100% · overflow: clip
- display: block · pointerEvents: none
- The `lvh` fallback is deliberate: a collapsing mobile address bar must not
  resize the WebGL buffer.

### `.sc-grain`
- position: fixed; inset: 0; zIndex: 3
- width: 1430px; height: 900px
- opacity: **0.03** (`scrollcraft.css` ships 0.045; `home.css` overrides it)
- pointerEvents: none
- `::before` — position: absolute; inset: -50%; backgroundImage: an inline
  `data:image/svg+xml` `feTurbulence` (`type='fractalNoise' baseFrequency='0.85'
  numOctaves='3'`) over a 140×140 rect.

### `.nh-progress[data-sc-progress]`
- position: fixed; inset: `env(safe-area-inset-top, 0px) 0 auto 0` → top: 0px
- width: 1430px; height: **3px**; zIndex: **95**
- backgroundImage: `linear-gradient(90deg, rgb(11, 114, 204), rgb(59, 170, 255))`
- boxShadow: `rgba(59, 170, 255, 0.55) 0px 0px 10px 0px`
- borderRadius: `0px 2px 2px 0px`
- transformOrigin: `0 50%`; transform: `matrix(0, 0, 0, 1, 0, 0)` (= `scaleX(0)`) at scroll 0
- `html:not(.sc-ready) .nh-progress { opacity: 0 }`

## States & Behaviors

### Paint gate
- **Trigger:** the engine adds `.sc-ready` to `<html>` at the end of `mount()`.
- **State A (before):** `main#top`, `.nh-pill` and `.nh-progress` at opacity 0.
- **State B (after):** opacity restored; no transition — the acts are pinned by
  the time anything paints.

### Reading progress
- **Trigger:** every engine frame.
- **Behaviour:** `transform: scaleX(p)` where `p` is document progress, 0 → 1.

### Glass uniforms (bound by the controller, per frame)
| Uniform | Bound to | Easing |
|---|---|---|
| `offsetY` | `-scrollY / vh * 0.22` | `1 - exp(-7·dt)` (coarse: `-5·dt`) |
| `offsetX` | `scrollY / vh * 0.03` | same |
| `intensity` | `0.22 + min(0.34, velocity·0.16)` | `1 - exp(-4·dt)` |
| `rotate` | `(ringProgress - 0.5) · 0.22` while the recognition stage is on screen, else `0` | none |

- **Velocity** is measured in viewport-heights per second and attacks faster than
  it decays: `vel += (v - vel) * (v > vel ? 0.35 : 1 - exp(-2.2·dt))`. On coarse
  pointers it is pinned to 0, because touch deltas arrive in bursts and would
  make the prism pulse.
- **Intensity floor** rises to 0.46 (fine) / 0.34 (coarse) while the ring stage
  is on screen — the brightest moment on the page.

### Shader configuration (`NHGlass.mount`, from the controller)
```
colors:  ['#EEF3F9', '#F9FBFD', '#CCE6FF', '#3BAAFF']
scale 1.18 · intensity 0.22 · paramA 0.34 · detail 1.824
contrast 1.0 · brightness 0.0 · saturation 1.0 · grain 0.032 · seed 3.0 · oklab 1.0
shadeBase 0.90 · shadeHighlight 0.13 · shadeShadow 0.06
cursorEnabled: fine && !reduced · cursorEffect 1.0 · cursorStrength 0.45 · cursorRadius 0.5
timeScale: (reduced || coarse) ? 0 : 0.3
maxPixels: coarse ? 380000 : 1000000 · maxDpr: coarse ? 1 : 1.25
```

### Hover states
N/A — `pointer-events: none` on all three. The shader's own cursor parallax is
read from `pointermove` on the window, only on fine pointers.

### Reduced motion
`timeScale: 0` freezes the field; the scroll bindings still run, so the light
still travels with the page but nothing animates on its own.

## Responsive Behavior
- **Desktop (1440px):** as above.
- **Tablet (768px):** identical; canvas 758×1024.
- **Mobile (390px):** identical geometry (380×844). The coarse branch drops
  `timeScale` to 0, caps the buffer at 380000 px and dpr at 1, and pins velocity
  so the prism holds still while the light travels with the scroll.
- **Breakpoint:** none. The only switch is `pointer: coarse`, not a width.
